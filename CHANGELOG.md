# Changelog

## 0.53.0 — unreleased

- Replaced hash-generated per-glyph wobble with a shared construction grammar.
- Harmonized curve phase across bowls and shoulders.
- Unified the terminal-angle family used by `e`, `c`, `r`, and `t`.
- Quieted the Grotesk `l` foot and `q` tail at UI sizes.
- Preserved stronger ambiguity cues in Local Mono’s 616-unit cell.
- Added a small-size consistency proof and a more human-authored specimen.

## 0.52.0 — 2026-07-29

- First public release of Local Grotesk and Local Mono.
- Added static Regular and Bold TTF and OTF builds.
- Added variable `wght` builds spanning 400–700 in TTF and WOFF2.
- Added LocalMono Nerd Font Mono Regular and Bold.
- Standardized shared `1000 / -250 / 0` line metrics.
- Fixed Local Mono printable ASCII to a 616-unit cell.
- Published editable FontForge sources, designspaces, proofs, and validation
  tools.
