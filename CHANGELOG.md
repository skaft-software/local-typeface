# Changelog

## 0.52.0 — 2026-07-29

- First public release of Local Grotesk and Local Mono.
- Added static Regular and Bold TTF and OTF builds.
- Added variable `wght` builds spanning 400–700 in TTF and WOFF2.
- Added LocalMono Nerd Font Mono Regular and Bold.
- Standardized shared `1000 / -250 / 0` line metrics.
- Fixed Local Mono printable ASCII to a 616-unit cell.
- Published editable FontForge sources, designspaces, proofs, and validation
  tools.
