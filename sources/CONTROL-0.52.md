# Local 0.52 control direction

Local is not a renamed Helvetica or IBM Plex derivative. The control set must
combine four distinct jobs:

- **Helvetica / TeX Gyre Heros:** neutral proportions, compact Swiss rhythm,
  disciplined spacing, and ordinary text color.
- **OpenDyslexic:** restrained lower-half gravity, unmistakable orientation,
  and deliberate asymmetry between forms that are commonly mirrored.
- **Atkinson Hyperlegible Mono:** open counters, generous apertures, and
  explicit differentiation of `I/l/1`, `O/0`, `b/d/p/q`, and `rn/m`.
- **IBM Plex Mono:** technical cadence, useful punctuation, and a credible
  terminal texture.

## Non-negotiable Local DNA

The personality is **wobble in the design logic, not noise on the contour**.

1. Curves use a delayed apex: the widest point lands slightly below or beside
   the mathematical center.
2. Lower bowls carry 2.5–4% more visual mass than upper bowls, without the
   cartoon base weight of OpenDyslexic.
3. Right-facing terminals share a shallow rising cut, varied by 2–4 units so
   repeated letters do not look stamped.
4. `b/d/p/q` are authored as related but non-mirrored shapes.
5. `c/e/s` stay open at text sizes.
6. Grotesk and Mono share terminal angles, dots, curve tension, ambiguity
   forms, and punctuation. Fixed width is a metric constraint, not a separate
   personality.

## Control glyphs

Do not propagate beyond this set before visual approval:

`a e g l r t n o s c b d p q I 1 O 0 R m { } [ ]`

## Recommended intensity

- Curve-apex displacement: 8–14 units per 1000 UPM.
- Terminal displacement: 6–10 units per 1000 UPM.
- Lower-half horizontal gravity: 2.5–3.5%.
- Mono cell: 616 units.
- At 14–16 px the changes should improve recognition without drawing
  attention. At 48–72 px the Local construction should be obvious.

## Bans

- No random point jitter.
- No sinusoidal edge distortion.
- No height compression.
- No universal bottom widening.
- No glyph may receive more than two unusual gestures.
- No claim that Local is clinically validated for dyslexia.
- No Geist outlines, metrics, or construction.
